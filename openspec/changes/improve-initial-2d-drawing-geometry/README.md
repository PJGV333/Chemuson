# Geometría inicial 2D — ChemUSON Beta 1

Esta campaña corrige la geometría por defecto de nuevas estructuras 2D; no reemplaza Clean2D y no cambia el renderer editorial.

- Propuesta/contrato: `proposal.md`, `specs/initial-2d-drawing-geometry/spec.md`.
- Auditoría/decisiones: `design.md`.
- Baseline exacto y diagnóstico: `baseline.md`, `baseline/`, `evidence/before/`.
- Trabajo verificable: `tasks.md` y `validation.md`.
- Generadores reproducibles: `evidence/reproduce_initial_2d_baseline.py` y `evidence/reproduce_initial_2d_after.py`.
- Capturas, métricas, modelo JSON y hashes posteriores: `evidence/after/`; instrucciones y aceptación pendiente: `validation.md`.

Las capturas posteriores usan la escena/renderer de producción a 1× y 1.25× con fondos de workspace claro/oscuro; el papel permanece blanco como en la aplicación. Son evidencia automatizada offscreen, no aceptación estética manual.

El archivo de prompt de la raíz no forma parte del OpenSpec ni de los commits. No se harán push, merge, PR, tag o publicación.
