# Avogadro 1.2 source evidence matrix (read-only)

| Behavior | Avogadro 1.2 evidence | ChemUSON baseline and design response |
|---|---|---|
| Draw preview and snapping | `libavogadro/src/tools/drawtool.cpp`: `mouseMoveEvent` (201–365) creates/removes a temporary endpoint and bond, checks hit atoms, reuses existing target atoms, and calls `moveAtom`; `moveAtom` (662–681) unprojects cursor coordinates through the camera. `mouseReleaseEvent` (370–479) composes undo commands. | Baseline ChemUSON used a dashed 2D line/circle. The implemented preview is a render-only 3D sphere/bond mesh in camera-plane world coordinates; picking stays on the document scene and target hits snap to existing atom coordinates. |
| Live MM visual feedback | `autoopttool.cpp`: `setupDone` starts a 50 ms timer (467–471); `timerEvent` invokes `m_thread->update()` (405–425); `AutoOptThread::update` performs force-field setup/steps (510–562). `paint` reports energy, ΔE and constraint count (227–249). | Baseline ChemUSON applied snapshots immediately; real worker events now arrive in sub-millisecond bursts. The implementation queues compatible snapshots, animates visual coordinates at a 16 ms tick with an 80 ms transition, keeps E/ΔE tied to real kcal/mol samples, and defers document publication until the final snapshot has played. No gradient is reported. |
| Tetrandrina path | ChemUSON local reproduction starts at the selected user-local template, imports a MolGraph, expands abbreviations on a copy, then reaches `_handle_graph_conformer3d_mode` and `_build_mol_from_graph_payload` before `Chem.SanitizeMol`. | Baseline fails at sanitization before ETKDG due to local aromatic bridge bond 9. Normalizing that flag alone does not repair identity: source atom 11 duplicates atom 6's 2D coordinates, is terminal, and occupies the endpoint of the missing 5–6 aromatic closure. The resulting 47-heavy-atom graph is `C39H46N2O6`; it is not the `C38H42N2O6` reference. The local MolBlock is imported faithfully and abbreviation expansion is correct. No user template correction was applied; see `identity-audit.md`. |
| Camera/navigation | Avogadro source provides camera unprojection/navigation context in DrawTool; no source code is reused. | ChemUSON now projects the camera basis into a persistent lower-left gizmo and shows temporary orbit arcs/status only when dragging empty space. Atom motion uses a separate geometry status and does not show the camera guide. Projection, gesture routing, and pick isolation have automated coverage; actual GUI/OpenGL pixels remain unverified pending manual acceptance. |
