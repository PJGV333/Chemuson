# ChemUSON 0.3.0-beta.4

**Idiomas:** Español (primero) · English (below).

## Español

> **Versión beta preliminar — no es una versión estable.** Está destinada a evaluación. Conserva copias de seguridad de tus trabajos importantes y verifica de forma independiente los resultados científicos.

### Cambios destacados

- **Nueva identidad visual del proyecto:** se incorpora el logotipo aprobado de ChemUSON a la aplicación, los paquetes de escritorio y la documentación. Se conservan los colores, proporciones, ilustraciones y tipografía de la imagen original. Es el emblema del proyecto ChemUSON; no es un escudo institucional oficial.
- **Mantenimiento de compilaciones:** se mejoró la separación de los artefactos generados respecto al código fuente y se conservó la evidencia histórica registrada.
- **Actualizador AppImage:** las nuevas versiones beta usan un selector de AppImageUpdate compatible con GitHub Releases, manteniendo la posibilidad de recibir betas posteriores y una versión final posterior.
- **Documentación y reconocimiento:** se aclara la clasificación excepcional de beta.3 en GitHub y se actualiza la lista documental de autores.

Beta.4 **conserva las capacidades científicas disponibles en beta.3**; esta campaña no añade ni anuncia funciones químicas nuevas.

### Actualizar desde beta.3

Cuando beta.4 esté publicada, utiliza únicamente los paquetes adjuntos a la [Release oficial](https://github.com/PJGV333/Chemuson/releases/tag/v0.3.0-beta.4), no los artifacts temporales de Build Preview. Verifica `checksums.txt` y `build-provenance.json` antes de abrir los archivos.

- **AppImage beta.3:** instala beta.4 manualmente desde la Release. El AppImage beta.3 publicado contiene el valor histórico `prerelease` como selector de actualización; AppImageUpdate lo trata como un tag literal, no como un canal. Sus tags, Release y archivos no se modifican. Las nuevas betas corrigen el selector.
- **Windows:** descarga el portable o el instalador oficial beta.4. Prueba la instalación en un perfil prescindible antes de sustituir una instalación existente.
- **Flatpak:** `flatpak update` actualiza las instalaciones conectadas al remoto beta oficial. Un bundle local de Preview no se conecta al canal público.

El Build Preview genera Windows portable, instalador Windows, AppImage Type 2 y Flatpak para evaluación. Sus artifacts son temporales y no son paquetes oficiales. Las verificaciones automatizadas no sustituyen la aceptación manual de los paquetes exactos.

### Clasificación en GitHub

La Release beta.3 aparece con el distintivo **Latest** porque el propietario cambió manualmente y de forma excepcional su metadato de GitHub a `prerelease=false`. El tag sigue identificando SemVer `0.3.0-beta.3`; esta decisión no es una regla para beta.4 ni para futuras betas. El workflow oficial conserva la clasificación prerelease derivada de SemVer y beta.4 no se promueve manualmente para obtener **Latest**.

### Limitaciones y seguridad

Esta es una beta. ChemName no garantiza cobertura general de nomenclatura IUPAC; las salidas espectroscópicas son estimaciones y el Asistente molecular es experimental. Verifica la identidad molecular y los resultados antes de utilizarlos en decisiones científicas.

Las actualizaciones y descargas deben verificarse mediante los checksums y la procedencia publicados. La edición molecular es local; si configuras un proveedor remoto para el Asistente, la solicitud se envía al servicio elegido. No envíes estructuras confidenciales sin autorización.

### Informar de errores

Abre una incidencia en <https://github.com/PJGV333/Chemuson/issues>. Indica sistema operativo, formato de paquete, versión, SHA de procedencia y pasos para reproducir el problema. No adjuntes claves API, tokens ni estructuras privadas.

## English

> **Pre-release beta — not a stable release.** It is intended for evaluation. Keep backups of important work and independently verify scientific results.

### Highlights

- **New project visual identity:** the owner-approved ChemUSON logo is integrated into the application, desktop packages and documentation. The original colors, proportions, illustrations and lettering are preserved. It is the ChemUSON project emblem, not an official University of Sonora seal.
- **Build maintenance:** generated artifacts are better separated from source code, while tracked historical evidence is preserved.
- **AppImage updater:** new beta packages use an AppImageUpdate selector supported by GitHub Releases, preserving updates to later betas and a later stable release.
- **Documentation and recognition:** the exceptional GitHub classification of beta.3 is clarified and the documented author list is updated.

Beta.4 **retains the scientific capabilities already available in beta.3**; this campaign does not add or announce new chemistry features.

### Updating from beta.3

When beta.4 is published, use only the assets attached to the [official Release](https://github.com/PJGV333/Chemuson/releases/tag/v0.3.0-beta.4), not temporary Build Preview artifacts. Verify `checksums.txt` and `build-provenance.json` before opening downloaded files.

- **beta.3 AppImage:** manually install beta.4 from the Release. The published beta.3 AppImage contains the historical `prerelease` update selector; AppImageUpdate treats that value as a literal tag, not a channel. Its tags, Release and assets remain unchanged. New beta packages correct the selector.
- **Windows:** download the official beta.4 portable executable or installer. Test installation in a disposable profile before replacing an existing installation.
- **Flatpak:** `flatpak update` updates installations connected to the official beta remote. A local Preview bundle is not connected to the public channel.

Build Preview produces Windows portable, Windows installer, Linux AppImage Type 2 and Linux Flatpak packages for evaluation. Its artifacts are temporary, not official downloads. Automated checks do not replace manual acceptance of the exact packages.

### GitHub classification

The beta.3 Release displays **Latest** because the owner exceptionally changed its GitHub metadata to `prerelease=false` manually. The tag still identifies SemVer `0.3.0-beta.3`; this decision is not a rule for beta.4 or future betas. The official workflow retains the prerelease classification derived from SemVer, and beta.4 is not manually promoted to obtain **Latest**.

### Limitations and security

This is a beta. ChemName does not provide general IUPAC coverage; spectroscopy results are estimates and the Molecular Assistant is experimental. Verify molecular identity and results before consequential scientific use.

Verify downloads with the published checksums and provenance. Molecular editing is local; if a remote Assistant provider is configured, the request is sent to that service. Do not submit confidential structures without authorization.

### Report bugs

Open an issue at <https://github.com/PJGV333/Chemuson/issues>. Include your operating system, package format, version, provenance SHA and reproduction steps. Do not attach API keys, tokens or private structures.
