## P1 — RDKit isolated backend unavailable in packaged executable (diagnóstico y fix)

- **Observación de propietario:** Windows portable entrega fórmula, masa y espectros estimados, pero informa `RDKit no disponible` para descriptores. El caso histórico `RDKIT-WIN-01` permanece `FAILED — P1`; las comprobaciones manuales quedan detenidas hasta un preview corregido. `RDKIT-WIN-02`, `RDKIT-LINUX-01` y `RDKIT-3D-SMILES-01` son retests nuevos `NOT TESTED`.
- **Reproducción de paquete congelado previo:** Build Preview `37849572146` terminó `success` sobre SHA `23e14ae71fe36d5df6b6b5a7d29fce867b507d4a`. Se descargó el AppImage Type 2 preview `Chemuson-v0.3.0-beta.1-preview-23e14ae7-linux-x86_64.AppImage`; su SHA-256 `57d3266511e192a8dd54ff437dd291d40a88652a84b62181e3ca5b44994cda4c` coincide con `checksums.sha256` y `preview-provenance.json`. Esto reproduce en el ejecutable real el defecto del despacho previo: `sys.executable` es el GUI EXE y no acepta el archivo worker como script Python.
- **Separación de import vs. despacho:** RDKit instalado local es `2026.03.6`; importan `rdkit.Chem.rdchem`, `rdkit.Chem.rdMolDescriptors` y `rdkit.Chem.rdDistGeom`. El nuevo smoke obligatorio verifica cada extensión dentro de `sys._MEIPASS` del worker congelado y hace fallar si usa el Python externo; los resultados por paquete se registrarán tras el siguiente Preview de Actions.
- **Corrección:** la ruta source conserva `[sys.executable, _rdkit_worker.py]`; el EXE congelado relanza su modo interno `--chemuson-internal-rdkit-worker` con request/response JSON temporales, sin stdin/stdout, sin GUI y sin import RDKit en el padre. Errores distinguen import, extensiones, spawn/bootstrap/exit, timeout, JSON y cálculo; el panel conserva filas parciales y reserva `RDKit no disponible` para fallo real de import.
