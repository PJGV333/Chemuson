# ChemUSON 0.3.0-beta.3

**Idiomas:** Español (primero) · English (below).

## Español

> **Versión beta preliminar — no es una versión estable.** Esta compilación está destinada a evaluación. Conserva copias de seguridad de tus trabajos importantes e informa de los problemas reproducibles mediante el sistema de incidencias del proyecto.

### Características destacadas

- **Editor molecular 2D:** permite crear y editar estructuras moleculares, anillos, enlaces, etiquetas de átomos, anotaciones y grupos químicos.
- **Clean2D:** mejora la distribución de las estructuras bidimensionales, conservando la conectividad molecular y la estereoquímica dentro de las reglas de validación implementadas.
- **Visualización molecular 3D interactiva:** visor integrado OpenGL, sincronización 2D→3D, generación de confórmeros mediante RDKit y edición de geometría. El comportamiento de Live MM depende de la estructura y del motor de cálculo seleccionado.
- **Herramientas científicas:** propiedades moleculares, estimaciones espectroscópicas, diagramas de energía, nomenclatura ChemName y paneles de análisis.
- **Asistente molecular experimental:** propuestas de estructuras asistidas por IA, con configuración explícita del proveedor y revisión por el usuario antes de aplicarlas.
- **Mejoras en el empaquetado:** se reforzaron las declaraciones de dependencias de ejecución y las verificaciones de recursos en aplicaciones empaquetadas. El asistente remoto opcional y las consultas a servicios externos siguen sujetos a la configuración del usuario.
- **Fiabilidad de la publicación:** beta.3 conserva el contenido funcional de beta.2; se creó para corregir la validación previa del procedimiento oficial de publicación, que ahora se ensaya de principio a fin en GitHub Actions antes de crear cualquier etiqueta oficial.

### Descargas e instalación

Utiliza únicamente los archivos adjuntos a [esta Release oficial](https://github.com/PJGV333/Chemuson/releases/tag/v0.3.0-beta.3), no los artefactos provisionales de GitHub Actions. Verifica los archivos publicados `checksums.txt` y `build-provenance.json` antes de ejecutar los paquetes descargados.

- **Windows x64:** utiliza el ejecutable portable o el instalador Inno Setup. Prueba primero la instalación en un perfil prescindible antes de sustituir una instalación existente.
- **Linux x86_64 AppImage:** concede permisos de ejecución (`chmod +x Chemuson-*.AppImage`) y ejecútalo. Si FUSE no está disponible, utiliza `--appimage-extract` y abre `squashfs-root/AppRun`.
- **Linux Flatpak:** instala el paquete adjunto con `flatpak install --user --bundle ./Chemuson-*.flatpak` y ejecútalo mediante `flatpak run --user --branch=beta io.github.PJGV333.Chemuson`. No añadas remotos de origen no verificado.

El flujo de compilación provisional genera Windows portable, instalador Windows, AppImage Type 2 y Flatpak desde un único SHA fuente. Las instrucciones específicas de instalación y verificación están en [PREVIEW_BUILDS.md](https://github.com/PJGV333/Chemuson/blob/release/v0.3.0-beta.3-prep/docs/release/PREVIEW_BUILDS.md). Los paquetes provisionales son evidencia temporal, no descargas oficiales.

### Limitaciones conocidas

- Esta es una beta. ChemName no garantiza cobertura general de la nomenclatura IUPAC, y Clean2D puede tener limitaciones con geometrías especialmente complejas.
- Las salidas espectroscópicas son estimaciones, no datos experimentales.
- El Asistente molecular es experimental: que un SMILES sea sintácticamente válido no demuestra que su estructura corresponda a la identidad solicitada. Revisa todas las propuestas antes de utilizarlas.
- La representación gráfica, la instalación y el funcionamiento pueden variar según el sistema operativo, controlador, entorno de escritorio y formato del paquete. Al informar de un problema, especifica el paquete y la plataforma exactos.

### Alcance de la evaluación manual

Estas notas no afirman que los paquetes específicos de beta.3 hayan recibido aceptación manual individual. El propietario informó observaciones limitadas de paquetes beta.1 que no identificaban los IDs de artefacto, el SHA fuente ni los checksums; la publicación fallida de beta.2 tampoco produjo archivos oficiales. Por ello, esas observaciones no establecen la aceptación de los archivos beta.3. Las validaciones automatizadas de compilación y empaquetado tampoco sustituyen una evaluación interactiva. Consulta la matriz de aceptación manual del proyecto; los casos sin evidencia permanecen sin verificar.

### Privacidad y seguridad

La edición molecular y el manejo de archivos se realizan localmente. Si utilizas un proveedor remoto para el Asistente molecular, la solicitud y la información molecular necesaria se envían al proveedor y quedan sujetas a su política de privacidad. No envíes estructuras confidenciales sin autorización para compartirlas. Las claves API se usan en la solicitud y no se guardan en las preferencias de ChemUSON; utiliza HTTPS para proveedores remotos. Los servidores locales LM Studio/llama.cpp pueden usar HTTP mediante la interfaz de bucle local. Las consultas externas opcionales de identidad o referencias requieren permiso explícito.

La búsqueda de actualizaciones es opcional y requiere activación por el usuario. Verifica siempre los checksums y la procedencia de los paquetes; es posible que algunos archivos no dispongan de firma.

El Flatpak conserva acceso a la red para el Asistente remoto configurado por el usuario y para las consultas externas de referencias habilitadas expresamente. Estas funciones pueden enviar solicitudes, información molecular o consultas al servicio elegido; disponer del permiso de red no equivale al consentimiento del usuario ni garantiza las prácticas de privacidad del proveedor. El Flatpak concede acceso directo al sistema de archivos únicamente en los directorios propios de configuración y estado de ChemUSON; abrir o guardar otros archivos requiere un permiso explícito mediante el portal de selección de archivos del escritorio y debe comprobarse en el paquete instalado.

## English

> **Pre-release beta — not a stable release.** This build is intended for evaluation. Save backups of important work and report reproducible problems through the project issue tracker.

## Highlights

- **Molecular editor 2D:** create and edit molecular structures, rings, bonds, atom labels, annotations and chemical groups.
- **Clean2D:** refine 2D layouts while keeping molecular connectivity and stereochemistry within the implemented validation rules.
- **Interactive molecular 3D:** integrated OpenGL viewer, 2D-to-3D synchronization, RDKit conformer generation and geometry editing. Live MM behavior depends on the selected backend and structure.
- **Scientific tools:** molecular properties, spectroscopy estimates, energy diagrams, ChemName nomenclature and analysis panels.
- **Experimental Molecular Assistant:** optional AI-assisted structure proposals with explicit provider configuration and review before applying.
- **Packaging hardening:** runtime dependency declarations and frozen-package resource checks were tightened; the optional remote Assistant and external lookups remain user-configured.
- **Release reliability:** beta.3 carries the same functional content as beta.2; it exists because the official publish preflight was repaired and is now rehearsed end-to-end in GitHub Actions before any official tag is created.

## Downloads and installation

When this prerelease is available, use only the assets attached to its GitHub release; do not use Actions preview artifacts as release packages. Verify the published `checksums.txt` and `build-provenance.json` before running a download.

- **Windows x64:** use the portable executable, or run the Inno Setup installer. Test an installation in a disposable profile before replacing an existing installation.
- **Linux x86_64 AppImage:** make the file executable (`chmod +x Chemuson-*.AppImage`) and launch it. If FUSE is unavailable, use `--appimage-extract` and start `squashfs-root/AppRun`.
- **Linux Flatpak:** install the attached bundle locally with `flatpak install --user --bundle ./Chemuson-*.flatpak`, then launch with `flatpak run --user --branch=beta io.github.PJGV333.Chemuson`. Do not add an unverified remote.

The preview workflow builds Windows portable, Windows installer, AppImage Type 2 and Flatpak packages from one source SHA. Package-specific installation and verification instructions are in [PREVIEW_BUILDS.md](https://github.com/PJGV333/Chemuson/blob/release/v0.3.0-beta.3-prep/docs/release/PREVIEW_BUILDS.md). Preview packages are temporary evidence, not official downloads.

## Known limitations

- This is a beta. ChemName does not guarantee general IUPAC coverage, and Clean2D may be limited on unusually complex geometries.
- Spectroscopy output is estimated, not experimental data.
- Molecular Assistant is experimental: a syntactically valid SMILES does not prove that a proposal matches the requested identity. Review all proposals before use.
- Graphics, installation and behavior can vary by operating system, driver, desktop environment and package format. Report the exact package and platform when describing a problem.

Automated build/package gates likewise do not substitute for interactive evaluation. Consult the project's manual-acceptance matrix; cases without evidence remain unverified.

## Privacy and security

Molecular editing and file handling are local. If you use a remote Molecular Assistant provider, the prompt and molecular information needed for the request are sent to that provider and are subject to its privacy terms. Do not submit confidential structures unless you are authorized to share them. API keys are used for the request and are not stored in ChemUSON preferences; use HTTPS for remote providers. Local LM Studio/llama.cpp endpoints may use loopback HTTP. Optional external identity/reference lookups require explicit permission.

Update checks are opt-in. Always verify package checksums and provenance; signing may not be available for every artifact.

The Flatpak keeps network access for a user-configured remote Assistant and explicitly enabled external reference lookups. Using these features can send prompts, molecular information or lookup queries to the selected service; the permission itself is not consent and does not guarantee that provider's privacy practices. The Flatpak grants direct filesystem access only to ChemUSON's own state/configuration directories; opening or saving other files requires an explicit desktop file chooser portal grant and must be checked on the installed package.
