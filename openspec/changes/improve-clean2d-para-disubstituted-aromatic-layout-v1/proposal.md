# Proposal: Improve para-disubstituted aromatic Clean2D layouts

## Why

The baseline para-disubstituted benzene case lacks a narrow topology-aware template, leaving its ring and exocyclic geometry to general candidates.

## What Changes

Add a deterministic `para_disubstituted_aromatic_template` for complete, neutral, stereo-free carbocyclic benzene systems with exactly two opposite one-atom terminal substituents. The template is limited to Quick and Publication modes.
