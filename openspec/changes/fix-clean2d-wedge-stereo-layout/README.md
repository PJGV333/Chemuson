# Clean2D con cuñas sólidas y rayadas

Microcampaña independiente: una molécula con un solo enlace en cuña (sólida o rayada) no se limpiaba nunca. Leer `proposal.md`, `design.md`, `specs/clean-2d/spec.md`, `tasks.md` y la evidencia versionada en `baseline.md` / `validation.md`.

El alcance no incluye ChemName, ChemIO, modelos químicos, GUI general, persistencia `.cmsn`, CompChem, packaging ni workflows. La rama se publica sola; no se integra automáticamente a la beta.
